## 学习目标

六周后应能达到以下目标：

1. 能解释源文件、目标文件、可执行文件、进程和线程之间的关系。
2. 能解释指令执行、函数调用约定、栈帧、缓存和虚拟内存的基本作用。
3. 能使用 `std::jthread`、`std::mutex`、`std::condition_variable` 编写线程安全程序。
4. 能识别数据竞争、死锁、虚假唤醒、丢失通知和关闭顺序错误。
5. 能使用 TSan、ASan/UBSan、GDB、`strace`、`/proc` 等工具观察和排查问题。
6. 能完成 EdgeBot 的单线程事件循环、有界任务队列、急停通道和优雅关闭。
7. 能区分 C++ 标准保证、标准库/运行时实现和 Linux 操作系统行为。

## 每周执行节奏

每周建议采用固定节奏：

1. **教材阅读 2 小时**：先读章节摘要，再精读与 EdgeBot 直接相关的部分。
2. **视频学习 2 小时**：只观看本周列出的讲次；遇到已经理解的内容可以跳过。
3. **编码实验 4～6 小时**：完成本周练习，不只看示例代码。
4. **观察与排错 1～2 小时**：保存命令、输出、错误现象和修复前后的对比。
5. **复盘记录 1 小时**：整理本周的“现象、复现、假设、证据、根因、修复、回归和遗留风险”。

每周结束时至少留下四类证据：

- 一份自己完成的代码。
- 一份可重复的测试或实验。
- 一次真实错误或性能现象的观察记录。
- 一段能在一两分钟内讲清楚的解释。

## 最终交付物

第 6 周结束时，应形成以下内容：

- 可编译的 MiniEdge 项目。
- 普通任务、高优先级急停和关闭策略的自动测试。
- 队列满、回调异常、优雅关闭的故障注入记录。
- TSan 和 ASan/UBSan 的运行记录。
- 一张线程所有权和任务队列关系图。
- 一份项目 `README.md`。
- 一份完整故障复盘。

建议的 MiniEdge 基本结构是：

```text
传感器生产者 ─┐
控制生产者   ─┼─> 线程安全 post ─> 有界任务队列 ─> 单线程事件循环
其他线程     ─┘                                  │
                                                  ├─> 设备会话状态
                                                  ├─> 诊断指标
                                                  └─> 结构化日志
```

急停任务应使用独立预留容量或专用通道，不能只依赖普通队列中的高优先级标签。

## 暂不深入学习的内容

以下内容不是当前求职目标的必要前提，可以后续再学：

- 处理器流水线和缓存一致性协议的内核级细节。
- 操作系统内核调度器和内存管理源码。
- 无锁数据结构和复杂原子内存序。
- 完整文件系统实现和崩溃一致性。
- 网络协议栈、分布式系统和数据库事务。
- 为了展示技巧而使用复杂模板、协程或 Rangess。

本阶段的主线是：**指令与调用约定 → 程序到进程 → 线程与互斥量 → 条件变量与队列 → 缓存与虚拟内存 → I/O 与综合项目**。只要能把这条主线落实到可运行代码、自动测试和真实观测数据，就已经达到本计划的核心目标。
